# KOReader 自适应自动翻页

![Lua 5.1](https://img.shields.io/badge/Lua-5.1-blue) ![License: MIT](https://img.shields.io/badge/License-MIT-green) ![KOReader 用户补丁](https://img.shields.io/badge/KOReader-user%20patch-orange)

[English](README.md) · **简体中文**

> 一个单文件 KOReader 用户补丁：从你自己的手动翻页节奏里学出间隔，再把这个间隔交给自动翻页，而不是让你去猜一个秒数。

KOReader 自带的 **AutoTurn** 插件按固定秒数翻页。本补丁用「实测值」替换这个固定猜测，且完全不修改 KOReader 源码。

---

## 设计初衷

AutoTurn 要求你填一个秒数。这个数字只能靠猜，而且怎么猜都容易出问题：

- **太短** —— 还没读完就翻页，得不停往回翻；
- **太长** —— 早读完了，却要干等它翻。

阅读速度是因人而异的，同一个人在一次阅读里也会变：进入状态后越读越快，累了或者遇到密集版面又会慢下来。一个写死的数字跟不上这种变化，而靠试错去调也很折腾——改一次设置、读一会儿、再改一次。

所以这里的思路很直接：**让阅读器自己量**。观察一段正常的手动翻页，只保留真正反映阅读节奏的间隔，取平均，再把结果交回 AutoTurn。你不需要猜任何数字。

由此引出几个设计取舍：

| 取舍 | 理由 |
| --- | --- |
| **全局单值，不按书隔离** | 阅读速度属于读者，不属于某本书。所有书共用一个学习值，打开新书不需要重新训练。 |
| **零侵入** | 以 `2-` 开头的用户补丁，只在运行时挂钩。不改 KOReader 源码、不写全局变量、不建目录、不写数据文件、不依赖 `lfs`。删掉文件即完全还原。 |
| **不打扰，直到你主动开启** | 开书时没有任何弹窗。补丁只在你**手动开启自动翻页**的那一刻介入。 |
| **合理样本一律保留** | 只剔除真正的异常值，不做近期加权：人往往越读越快，给近期样本加权会把结果往「翻页过快」拉。取全期均值，保留从容、真实的节奏。 |
| **失败即静默** | 所有 `require`、接口探测、界面调用、hook 都包在 `pcall` 里。符号缺失或 KOReader 版本不同，只记一条日志然后让开，绝不影响 KOReader 启动。 |

## 功能说明

**触发方式。** 当你在菜单里把自动翻页从**关 → 开**时，补丁拦下这个动作并弹出间隔选择框；**开 → 关**直接放行原逻辑。开书全程静默。

**间隔选择框**提供四个选项：

| 选项 | 行为 |
| --- | --- |
| 使用已有数据 | 立即按已保存的学习值开启自动翻页；尚无学习值时置灰不可用 |
| 重新训练 | 从你的手动翻页中重新学习间隔 |
| 手动设置 | 输入 3~120 的整数秒；输入非法会提示并可重新输入 |
| 取消 | 不开启自动翻页，不做任何改动 |

**学习流程**

1. 先弹一个 **3 秒页面提示**。此时自动翻页已挂起、且不计样本——提示还停在屏幕上时的点击不会被记进去。
2. 提示关闭后正式开始采集。自动翻页保持关闭，你像平时一样手动翻页。
3. 采够 **40 个有效间隔**即自动结束；另设 **30 分钟**兜底超时，两者先到先结算。
4. 学习值写入设置，自动翻页按该间隔开启。
5. 若有效数据不足，则**不覆盖**已有学习值，按默认 120 秒开启并提示可重新训练。

### 间隔是怎么算出来的

只剔除**异常**间隔，合理范围内的值全部保留，最后对整段采集取平均。

| 方向 | 规则 | 针对什么 |
| --- | --- | --- |
| 特别大 | `间隔 > 中位数 × 3` | 离开、走神、长时间中断 |
| 特别小（采样阶段） | `间隔 < 6 秒` 不入池，但仍推进计时基准 | 误触、连翻，例如 5 秒的双击 |
| 特别小（统计阶段） | `间隔 < max(6 秒, 中位数 × 0.4)` | 相对你自身节奏异常快的间隔 |

刻意**不做**双侧 IQR、不丢阅读碎片段、不做近期加权：前两者会把「读得慢」的合理样本删掉、把均值压小，后者会跟着越读越快的趋势把均值拉小，结果都是翻页太快。最终值会 clamp 到 3~120 秒并四舍五入。

只有**相邻向前翻页**才计入。跳转、回翻、目录/书签/搜索定位、连续快翻的翻找模式、以及自动翻页产生的翻页都会被排除。计时使用 KOReader 的单调时钟，休眠唤醒不会让样本被墙上时间跳变污染。

## 安装

1. 把 `2-adaptive-autoturn.lua` 放到 `koreader/patches/`。
2. 保持文件名以 `2-` 开头——这表示在 UIManager 就绪后的 late 阶段加载。
3. 重启 KOReader，确认已启用 **AutoTurn** 插件，且处于分页视图（非滚动模式）。

请勿与其他同样包裹 AutoTurn 的补丁同时使用，否则 hook 会叠加。

## 卸载

删除该文件（或改名为 `.disabled`）并重启即可。不会留下源码改动、数据文件或全局状态。

## 参数配置

所有可调项都在文件顶部的 `CFG` 表里，改完重启 KOReader 生效。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `setting_key` | `adaptive_autoturn` | 存于 `G_reader_settings` 的设置项名 |
| `hint_timeout` | `3` | 页面提示停留秒数，关闭后才开始采集 |
| `target_samples` | `40` | 采够多少个有效间隔即结束 |
| `train_timeout_min` | `30` | 兜底超时（分钟） |
| `min_interval` | `2` | 小于此值计入「翻找模式」判定 |
| `abs_min_keep` | `6` | 绝对下限，更小的间隔绝不入池 |
| `max_interval` | `300` | 可记录的最长间隔 |
| `burst_count` | `3` | 连续快翻多少次触发计时重置 |
| `min_samples` | `8` | 结果有效所需的最少样本数 |
| `min_after_trim` | `5` | 剔除异常值后剩余样本下限 |
| `outlier_factor` | `3` | 上界＝中位数的倍数 |
| `small_outlier_ratio` | `0.4` | 下界＝中位数的比例 |
| `min_sec` / `max_sec` | `3` / `120` | 学习值 clamp 区间 |
| `default_sec` | `120` | 采集失败时的兜底间隔 |
| `suspend_sec` | `86400` | 采集期用于挂起自动翻页的间隔 |

## 数据与隐私

唯一的持久状态是 `G_reader_settings.adaptive_autoturn` 中的一项，由 KOReader 自己写进 `settings.reader.lua`：

```lua
{
  learned_sec   = 42,   -- 学习到的间隔（秒）
  trained       = true, -- 是否已有有效学习值
  last_duration = 30,   -- 本次训练所用兜底超时（分钟）
}
```

补丁不创建目录、不写文件、不上传任何数据。原始翻页间隔只存在于采集期间的内存中，结算后即丢弃。若想清除学习值，删除 `settings.reader.lua` 里的 `adaptive_autoturn` 项即可。

## 兼容性与限制

- 纯 **Lua 5.1**，零全局写入。
- 运行时按 KOReader 真实符号探测（`ReaderReady`、`PageUpdate`、AutoTurn 字段与 `_schedule` / `_unschedule`、`UIManager`、各类 widget），不硬编码接口。未来版本若内部结构变化，补丁会检测到不匹配并静默让开，而不是让 KOReader 起不来。
- **仅支持分页视图**，切换到滚动模式会中止采集并提示。
- 学习值是全局的。如果漫画与密集文字的阅读速度差别很大，这类场景可用「手动设置」。
- 尚未覆盖所有设备与 KOReader 版本组合，欢迎反馈具体固件 / 插件版本的兼容性。
