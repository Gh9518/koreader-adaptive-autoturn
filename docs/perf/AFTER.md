## 真机验证步骤（交由用户执行，口径与基线一致）

沙箱无 KOReader 设备，按用户决策以 stub 测试覆盖逻辑，真机验证请按以下步骤进行：
1. 将 `2-adaptive-autoturn.lua` 放入设备 `koreader/patches/`，重启 KOReader（确认 AutoTurn 插件已启用、分页视图）。
2. 进入任意书籍 → 菜单开启 Autoturn → 选择「自动设置」→ 按提示正常手动翻页约 40 页。
3. 观察底部提示「学习完成，自动翻页间隔已设为 N 秒」，确认自动翻页按该间隔生效。
4. 查看 `koreader/crash.log` 中 `aat:` 行，确认出现 `collection done reason= enough samples=40 learned=N`。
5. 关书→再开书，菜单开启 Autoturn →「当前间隔」应显示上一步学到的 N 秒，验证跨会话持久化与无残留样本。
6. 回滚方式：删除或改名 `2-adaptive-autoturn.lua` 为 `.disabled` 并重启，即完全还原原生行为（本补丁不写任何数据文件）。
